# Renovation Company Website

Multi-page website for a renovation and interior design business: services (apartments, commercial spaces, houses), materials, and portfolio-style sections.

> Status: **Portfolio / commercial-style site**. Live demo via GitHub Pages when enabled.

## What’s included

- Service pages (renovation packages, interior design)
- Materials / catalog-style pages
- Home and supporting PHP pages
- Front-end assets: HTML, CSS, JS, images

## Stack

- PHP (multi-page)
- HTML / CSS / JavaScript
- Static assets under `css/`, `js/`, `img/`, `components/`

https://stardmitriu.github.io/qusaq.online/

## Local viewing

This project is structured as PHP pages. For a quick look at markup/assets you can open static files or run a local PHP server from the project root:

```bash
php -S localhost:8000
```

Then open `http://localhost:8000/home.php` (or `index.php` depending on entry).
