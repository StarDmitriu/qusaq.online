# Renovation Company Website

Multi-page site for a renovation and interior design company. Covers services for apartments, commercial spaces, and houses, plus materials and portfolio-style sections.

## Pages & sections

- Home and services overview
- Renovation packages and interior design
- Materials / catalog-style pages
- Supporting PHP pages and shared front-end assets

## Stack

- PHP
- HTML / CSS / JavaScript

## Live demo

https://stardmitriu.github.io/qusaq.online/

## Run locally

From the project root:

```bash
php -S localhost:8000
```

Then open `http://localhost:8000/home.php` (or `index.php`, depending on the entry you want).
